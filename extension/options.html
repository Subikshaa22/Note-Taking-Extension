Setup guide

Notes server

Where the note-taking backend runs. The default matches docker compose up.

Notion destination

Paste a Notion page link or id. Notes are created inside it. Leave empty to use the server's default: the page set in NOTION_DEFAULT_PARENT_ID, otherwise the most recently edited top-level page you shared with the integration.

Notion access

Use Connect Notion in the popup if your server has an OAuth app set up. Otherwise, use an integration token:

  1. Create an Internal integration at notion.so/profile/integrations and copy its secret (it starts with ntn_).
  2. In Notion, open the page your notes should go under and use ⋯ → Connections to add the integration.
  3. Paste the secret below and click Use this token.
