Video Notes — Settings

Notes server

Where the note-taking backend runs. The default matches docker compose up.

Notion destination

Paste a Notion page link or id. Notes are created inside it. Leave empty to use the server's default: the page set in NOTION_DEFAULT_PARENT_ID, otherwise the most recently edited top-level page you shared with the integration.

Notion access

Prefer Connect Notion in the popup (one-time sign-in). If the server has no OAuth app configured, paste an internal integration secret instead (Notion → Settings → Connections → Develop or manage integrations), and share your destination page with that integration.
