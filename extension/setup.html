Video Notes — Setup guide
Settings

Video Notes turns a YouTube video into study notes with real frames from the video, and saves them as a Notion page. It needs three things: the notes server running on your computer, access to Notion, and (optionally) a Notion page to put the notes in.

1Start the notes server

You need Docker Desktop (open and running) and a free Gemini API key. Run these in a terminal inside the project folder.

  1. Create your settings file:
    copy .env.example .env
    On macOS or Linux use cp .env.example .env.
  2. Open .env in a text editor and set GEMINI_API_KEY= to your key.
  3. Start everything (the first run takes a few minutes):
    docker compose up --build -d
  4. Click Check again at the top. Notes server should turn green.

To stop the server later, run docker compose down. If port 8000 is taken, set GATEWAY_PORT=8001 in .env and change the gateway address in Settings to http://localhost:8001.

2Give Video Notes access to Notion

Pick one option. Option A is quickest.

Option A: integration token (about 2 minutes)

  1. Go to notion.so/profile/integrations, click New integration, choose Internal, give it a name and save.
  2. Copy its Internal Integration Secret (it starts with ntn_).
  3. In Notion, open the page your notes should go under, click ⋯ → Connections and add your integration. This lets it create pages there.
  4. Open Settings → Notion access, paste the secret and click Use this token.

Keep the secret private. It works like a password for the pages you connected.

  4. Open the Video Notes popup, click Connect Notion and choose the pages to share.

3Choose where notes go (recommended)

  1. In Notion, open the page you connected and click Share → Copy link.
  2. Paste it into Settings → Notion destination and click Save settings.

Every video becomes a new page inside that page. Nothing is ever overwritten. If you leave the destination empty, the server uses NOTION_DEFAULT_PARENT_ID from .env if set, otherwise the page you shared with the integration (the most recently edited one if you shared several).

4Take notes

  1. Open a YouTube video that is 20 minutes or shorter. Longer videos are rejected.
  2. Press Take Notes in the player's bottom-right toolbar, or open the Video Notes popup and click Take Notes there.
  3. Open the popup to watch progress: Queued → Transcribing → Summarizing → Extracting frames → Publishing → Done.
  4. When it finishes, click View in Notion (you also get a desktop notification).

Tip: pin Video Notes to the toolbar with the puzzle-piece icon so the popup is one click away.

Troubleshooting

The popup says “Not connected”.
Notion access isn't set up yet. Follow step 2. Connecting the integration inside Notion isn't enough on its own; the secret also has to be pasted into Settings.
“Can't reach the notes server”.
Docker Desktop isn't running or the server is stopped. Start Docker, then run docker compose up -d in the project folder. Check the address in Settings.
I don't see the Take Notes button on YouTube.
Reload the YouTube tab after installing or reloading the extension. The button only appears on video pages (youtube.com/watch).
A job says “Waiting — retrying in 30s”.
An external service (Gemini, Notion or YouTube) asked us to slow down. The job retries on its own; no action needed.
A job failed saying the destination wasn't found.
The destination page isn't shared with your integration. In Notion, open it and add the integration under ⋯ → Connections.
A job failed with “Video too long”.
Only videos up to 20 minutes are supported.
I changed the extension's files.
Go to chrome://extensions and click the reload icon on Video Notes, then reload any YouTube tabs.
